Privacy Policy – jobradar

Last updated: 19 November 2026

jobradar is a personal tool used only by its owner, on the owner's own computer.

What data is accessed

With the owner's consent, jobradar uses the Gmail API with the read-only scope gmail.readonly to read job alert emails in the owner's own Gmail account. It cannot send, delete or change emails.

How data is used and stored

  • Email content is used only to extract job ads (title, company, location, link) for the owner's personal job search.
  • All data is stored locally on the owner's computer. The access token is stored in the macOS Keychain.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

jobradar's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
